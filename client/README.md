# Portfolio client

The React + Vite frontend for Jonathan Marshall's portfolio. See the [project README](../README.md) for architecture, resume/content updates, contact configuration, accessibility checks, and Render deployment.

Run these commands from this directory:

```bash
npm ci
npm run dev
```

Before committing:

```bash
npm run lint
npm test
npm run build
```

Use `npm run preview` to inspect the production build locally. The test script checks the embedded pathfinding comparison.
